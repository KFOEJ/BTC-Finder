Super simple Python script.
Searches privatekeys.pw randomly for pages with balance.
If a page with balance is found, script saves data to "positive_balances.txt".

--------------------------------

TO RUN
- OPEN TERMINAL/CONSOLE IN SCRIPTS FOLDER
- Windows : python ./script.py
- Linux : Chmod +x script.py | ./script.py
